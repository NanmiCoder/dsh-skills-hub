# Skills Hub 0.0.1

Initial release of `@nanmicoder/dsh-skills-hub` for DeepSeek Harness's 0.2.0 desktop line (exact package baseline: `0.2.0-rc.2`).

- ClawHub and SkillHub browsing, search, deduplication and source health.
- Skeleton loading for marketplace and skill details, bundled Markdown rendering and automatic scroll pagination.
- Marketplace installation, local skill discovery and an Installed management view with confirmed removal.
- Atomic installation, existing-directory conflict protection and restricted filesystem removal.
- Scoped npm package, bilingual documentation, pinned compatibility metadata and reproducible build/package/release checks.

Install in **DeepSeek Harness desktop → Plugins → Add plugin**. Paste `https://github.com/NanmiCoder/dsh-skills-hub` (recommended) or `@nanmicoder/dsh-skills-hub`, click **Install**, then **Enable now**. Open **Skills Hub** from the sidebar. Installing the plugin does not migrate or delete existing skills.
