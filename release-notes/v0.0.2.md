# Skills Hub 0.0.2

`@nanmicoder/dsh-skills-hub` for DeepSeek Harness **0.2.0-rc.2**.

- Persist browsed catalogue pages, searches, skill details and file previews across desktop restarts. The default cache lifetime is 60 minutes, configurable through `cacheTtlMinutes`.
- Preserve snapshot timestamps and each page's provenance. Reopening a detail checks the Host's cache lifetime and current local installation state.
- Keep installation manifests fresh: actual installs bypass cached details and refuse stale fallback when upstream fails.
- Bound and validate disk snapshots, recover abandoned temporary writes, and keep provider configurations isolated during reloads.
- Show installed skills in a full detail page, with rendered Markdown previews, structured frontmatter and a source view for file contents.
- Prefetch the next catalogue page near the end of the current view, and show snapshot age with an explicit refresh action.

Install in **DeepSeek Harness desktop → Plugins → Add plugin** using `@nanmicoder/dsh-skills-hub@0.0.2`, then enable the plugin. Existing skills remain in place. Advanced cache settings are documented in [CONFIGURATION.md](../docs/CONFIGURATION.md).
