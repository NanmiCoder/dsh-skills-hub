# Skills Hub 0.0.5

Fix installation on DeepSeek Harness **0.2.1-rc.2**, retaining support for **0.2.1-rc.1**. Version 0.0.4 declared only rc.1, so rc.2 hosts rejected it during compatibility validation.

- Develop against the exact rc.2 cohort and allow both verified candidate host versions in peer dependencies.
- Document selecting the official npm registry: mainland mirror metadata can remain on 0.0.3 and cannot resolve newer versions until synchronized.
- Continue publishing stable plugin releases to npm `latest`; host candidate versions and plugin publication channels are separate.

After publication, select the official npm source in Add plugin and install `@nanmicoder/dsh-skills-hub@0.0.5`. Existing skills are preserved. This does not claim support for future untested host versions.
